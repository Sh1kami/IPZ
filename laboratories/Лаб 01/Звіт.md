## Теоретичні відомості

Тестування порівнює фактичну поведінку програми з очікуваною. Функціональні перевірки стосуються правил і можливостей, нефункціональні оцінюють швидкодію, надійність, сумісність та захист. Позитивні сценарії використовують допустимі дані, негативні перевіряють коректну відмову.

Юніт-тести ізолюють окрему функцію. Інтеграційні охоплюють взаємодію компонентів, системні проходять користувацький шлях, а приймальні перевіряють критерії замовника. Регресійний набір запускають після зміни коду, щоб виявити порушення попередньої поведінки.

Дефект проходить реєстрацію, класифікацію, виправлення, повторну перевірку та закриття. Запис містить передумови, відтворювані кроки, дані, очікуваний і фактичний результати, важливість та доказ. JUnit забезпечує незалежний запуск тестів і автоматичне порівняння результатів через assertions.


## Хід виконання

Об’єкт тестування - сервіс пошуку роботи з ролями гостя, шукача та роботодавця. Основні функції: реєстрація і вхід, резюме, публікація вакансій, пошук, фільтрація та відгук. Для них визначено вимоги FR01–FR06 і матрицю простежуваності.

Створено Maven-проєкт для Java 17 з JUnit 4.13.2, SQLite JDBC та Gson. JUnit-тести розміщено в src/test/java. Maven Surefire запускає їх і формує XML та текстові протоколи.

StartupTest створює тимчасову SQLite, запускає справжній HTTP-сервер на вільному порту та перевіряє /api/health, порожній каталог і головну сторінку. Try-with-resources завершує сервер після тесту; TemporaryFolder ізолює дані.


```text
mvn -B -ntp -Dtest=StartupTest verify
```


```
package ua.edu.kntu.jobs;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.file.Files;
import org.junit.Rule;
import org.junit.Test;
import org.junit.rules.TemporaryFolder;
import static org.junit.Assert.*;

/** Minimal LR1 environment check: real HTTP startup, schema and resource, no mocked server. */
public class StartupTest {
    @Rule public TemporaryFolder temp = new TemporaryFolder();
    @Test public void realServerStartsOnDynamicPortAndServesHealthAndEmptyCatalog() throws Exception {
        var db = temp.getRoot().toPath().resolve("startup.sqlite");
        try (var portal = new JobPortalServer(db).start(0)) {
            HttpClient client = HttpClient.newHttpClient();
            HttpResponse<String> health = client.send(HttpRequest.newBuilder(URI.create(portal.baseUrl()+"/api/health")).GET().build(),HttpResponse.BodyHandlers.ofString());
            assertEquals(200,health.statusCode()); assertTrue(health.body().contains("\"variant\":26"));
            HttpResponse<String> jobs = client.send(HttpRequest.newBuilder(URI.create(portal.baseUrl()+"/api/jobs")).GET().build(),HttpResponse.BodyHandlers.ofString());
            assertEquals(200,jobs.statusCode()); assertTrue(jobs.body().contains("\"count\":0"));
            HttpResponse<String> page = client.send(HttpRequest.newBuilder(URI.create(portal.baseUrl()+"/")).GET().build(),HttpResponse.BodyHandlers.ofString());
            assertEquals(200,page.statusCode()); assertTrue(page.body().contains("resume-form"));
            assertTrue(Files.size(db)>0); assertFalse(portal.baseUrl().endsWith(":0"));
        }
    }
}

```


## Результати виконання

StartupTest виконав один JUnit-тест без failures, errors і skipped. GET /api/health, GET /api/jobs і GET / повернули 200. Початковий count дорівнює 0; SQLite-файл створено, динамічний порт призначено.

Матриця вимог дає основу для наступних лабораторних. Фактичні запуски бізнес-сценаріїв наведено у відповідних роботах; StartupTest підтверджує саме готовність середовища.
