# Переходи станів

Гість → реєстрація → вхід → SEEKER або EMPLOYER → вихід → гість.
Резюме: відсутнє → створене → оновлене; невдале оновлення зберігає стан.
Вакансія: ACTIVE → CLOSED → ACTIVE, лише власник.
Відгук: відсутній → створений; повторний запит не змінює кількості.
