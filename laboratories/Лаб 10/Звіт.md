## Завдання

Визначити критичні функції, підготувати автоматизований набір, внести контрольну зміну, виявити порушення, виправити його й повторити перевірку.


## Теоретичні відомості

Регресійний тест перевіряє збереження вже визначеної поведінки після зміни. Високий пріоритет мають основні користувацькі шляхи, граничні значення й ділянки поруч зі зміною.

Повторна перевірка конкретного дефекту підтверджує виправлення, а ширший регресійний набір шукає побічні наслідки. Тест має спиратися на попередній контракт: зміна очікування під нову помилкову реалізацію приховала б дефект.

Для відтворення помилки достатньо контрольної зміни в ізольованій копії коду. Оригінальний робочий застосунок зберігається, а журнали показують різницю між помилковою та виправленою поведінкою.


## Хід виконання

RegressionTest містить шість перевірок: включна нижня межа зарплати, значення вище межі, регістр пошуку й міста, поєднання фільтрів і невідповідний формат роботи.

В окремій копії JobFilter оператор salary >= minSalary замінено на salary > minSalary. За вимогою вакансія із зарплатою 40000 має входити в результат для minSalary=40000. Зміна порушує саме цю умову.

Запуск виявив два падіння: salaryLowerBoundary і combinedFilters. Дефект REG01 задокументовано з передумовами та очікуванням. Після відновлення >= усі шість тестів пройшли; повний актуальний Java-набір також успішний.


```text
mvn -B -ntp -Dtest=RegressionTest test
```


```
package ua.edu.kntu.jobs;
import org.junit.*;
import static org.junit.Assert.*;
import java.util.List;
import ua.edu.kntu.jobs.Models.*;
public class RegressionTest {
    private Job job;
    @Before public void setup(){job=new Job(1,1,"Java Developer","IPZ Company","Київ",40000,true,"Опис Java розробника для тестування.",JobStatus.ACTIVE,"2026-11-19T00:00:00Z");}
    @Test public void salaryLowerBoundary(){assertTrue(new JobFilter("java",null,40000,null,null).matches(job));}
    @Test public void salaryAboveBoundary(){assertFalse(new JobFilter("java",null,40001,null,null).matches(job));}
    @Test public void caseInsensitiveSearch(){assertTrue(new JobFilter("JAVA",null,0,null,null).matches(job));}
    @Test public void cityCaseInsensitive(){assertTrue(new JobFilter(null,"КИЇВ",0,null,null).matches(job));}
    @Test public void combinedFilters(){assertTrue(new JobFilter("java","Київ",40000,true,"ACTIVE").matches(job));}
    @Test public void remoteMismatch(){assertFalse(new JobFilter("java",null,0,false,null).matches(job));}
}

```
