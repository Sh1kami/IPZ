## Теоретичні відомості

Мобільні перевірки враховують життєвий цикл Activity, розмір екрана, орієнтацію, клавіатуру та навігацію. Поворот може перевідтворити Activity, тому важливий стан потрібно зберігати через onSaveInstanceState.

Appium приймає WebDriver-команди та передає їх драйверу UiAutomator2. Capabilities задають платформу, застосунок, пакет, Activity й пристрій. Accessibility ID дає змогу знаходити елементи без залежності від координат.

Після зміни орієнтації старі посилання на елементи стають неактуальними. Очікування повторно знаходить елемент і враховує тимчасовий StaleElementReferenceException.


## Хід виконання

Створено Android-каталог IPZ Jobs: пошук вакансій, список, деталі та скидання. Екран показує дані студента. Пошуковий рядок зберігається під час відтворення Activity.

Зібрано debug APK через Gradle 8.9 та JDK 17. Для виконання використано Android 9, API 28, x86_64, Appium 3.1.0 та UiAutomator2 5.0.5. Налаштовано телефонний екран 480×800 і планшетний 800×1280 з density 160.

На кожному профілі виконано шість сценаріїв: старт, пошук JAVA, деталі, збереження пошуку після повороту, порожній пошук Rust і скидання. Після повороту перевіряються і текст запиту, і кількість результатів.
