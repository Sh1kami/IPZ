# Лабораторна робота 4
## Автоматизація тестування

Панчишкін Богдан Олександрович, група 3ПРс/3.

Цей каталог містить вихідний код застосунку, тести та результати роботи.
Java-проєкт: JDK 17+, Maven 3.9+; базовий запуск усіх Java-перевірок — `mvn -B -ntp verify`.

Основна команда цієї роботи:
```text
python tests_external/browser_checks.py
```

Інструкції підготовки Docker, Selenium, Postman і Appium:
https://github.com/Sh1kami/IPZ#readme

Звіт і PDF-посилання на код розташовано на один рівень вище.
