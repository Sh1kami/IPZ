# План тестування сервісу пошуку роботи

Автор: Панчишкін Богдан Олександрович, 3ПРс/3.
Об’єкт: Java HTTP-сервіс, SQLite, браузерний інтерфейс та Android-каталог вакансій.
Ролі: гість, шукач, роботодавець. Дані: навчальні адреси example.test.

Ризики: втрата резюме, дублікати відгуків, зміна чужих вакансій, обхід входу,
помилковий пошук на граничній зарплаті, SQL injection та stored XSS.
Спочатку перевіряються ці ризики, далі UI й нефункціональні властивості.

Рівні: чисті доменні JUnit-тести; service+SQLite; HTTP+SQLite;
Selenium end-to-end; Appium Android; Gherkin/Cucumber; JMeter.
Вхід: застосунок зібрано, тестова база окрема, інструменти готові.
Вихід: очікувані відповіді збігаються, блокувальні дефекти закриті,
для локального навантаження p95 <= 500 мс і 0 HTTP-помилок.
Результати кожного інструмента обліковуються окремо; покриття JaCoCo стосується
Java-коду. Швидкодія Android у програмній емуляції не використовується як
вимір швидкості фізичного пристрою.
